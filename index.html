Fiches Pratiques Accessibles

Guide d'utilisation du smartphone pour personnes déficientes visuelles et non-voyantes

Accessibilité & Voix

Activer et désactiver VoiceOver par le bouton latéral

Marche à suivre :

  • Aller dans Réglages > Accessibilité > Raccourci d’accessibilité.
  • Cocher VoiceOver.
  • Désormais, en appuyant trois fois sur le bouton latéral, VoiceOver s’active ou se désactive.

Activer / désactiver la synthèse vocale et le rideau d’écran

  • Synthèse vocale : Taper 2 fois avec 3 doigts sur l’écran.
  • Rideau d’écran (masquer l'affichage) : Taper 3 fois avec 3 doigts sur l’écran.

Communication, Appels & Mails

Appel vocal, SMS et Agenda (Siri)

  • Appel vocal : Appuyer sur le bouton latéral (ou central), puis dire le nom du contact. Pour raccrocher : taper deux fois avec deux doigts n'importe où.
  • Envoyer un SMS : Appuyer sur le bouton, dire "envoyer un message à [nom]". Dicter, puis dire "envoyer le message", "modifier" ou "supprimer".
  • Agenda vocal : Demander "ajouter un évènement au calendrier", puis dicter le nom, la date et l'heure. Pour consulter : "Ai-je des rendez-vous demain ou la semaine prochaine ?"

Gestion de la boîte Mail et gestes tactiles

Gestes essentiels :

  • Ouvrir : 2 touches rapides avec 1 doigt. Élément suivant/précédent : glisser de droite à gauche ou gauche à droite].
  • Pause/Lecture : 2 touches rapides avec 2 doigts. Lecture complète : glisser de haut en bas avec 2 doigts.
  • Retour page précédente : Faire un "Z" avec 2 doigts sur l'écran.

Mails : Ouvrir Mail (2 taps), parcourir les messages, glisser de haut en bas sur un mail pour "supprimer" ou "répondre". Pour dicter : taper 2 fois avec 2 doigts pour activer le micro, puis répéter pour couper avant d'envoyer.

Code PIN et ajout d'un contact

  • Code PIN SIM : Taper 2 fois avec 1 doigt sur le chiffre, placer le doigt en haut et glisser à droite jusqu'à entendre "OK", puis taper 2 fois.
  • Ajouter un contact : Aller dans Téléphone > Contacts > Ajouter. Saisir le nom, puis "ajouter un numéro", taper le chiffre et valider "OK".
  • Depuis un appel récent : Dans "Contacts récents", sélectionner le numéro, maintenir avec une double tape (collée) jusqu'au bip pour ouvrir le menu et choisir "Nouveau contact"].

Sécurité & Codes

Changer le code PIN de la carte SIM

  • Aller dans Réglages > Données cellulaires.
  • Sélectionner PIN de la carte SIM.
  • Aller sur Modifier le PIN.
  • Saisir le PIN actuel et valider, puis définir et confirmer le nouveau PIN.

Code de déverrouillage de l'écran

  • Aller dans Général > Face ID et code (ou Touch ID et code).
  • Taper le code actuel.
  • Descendre sur "Changer le code" et retaper le code actuel.
  • Aller sur "Option des codes" pour choisir un format (ex: code à quatre chiffres), puis saisir et confirmer le nouveau code.

Activer et désactiver le service d'urgence (SOS)

  • Étape 1 : Ouvrir les Paramètres / Réglages.
  • Étape 2 : Appuyer sur « Sécurité et urgence ».
  • Étape 3 : Appuyer sur « SOS d'urgence ».
  • Étape 4 : Activer ou désactiver le commutateur.
